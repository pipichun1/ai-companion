## 她发图（表情包）—— 暂搁置

**目标**：让 App 里也能看到她发表情包，复用 AstrBot 里已有的表情包库。

**探针结论**（2026-11-27 实测）：

```
1. webchat 队列只传三种数据：plain 文字 / complete 文字 / end
   图片根本不会进入队列

2. AstrBot 数据库 42 个会话里，含图片的：0 个
   她发的图不进历史记录

3. meme_manager 用 event.send(消息链含 Image)
   这种消息链只有 QQ 类平台支持，webchat 不认
```

**所以卡点在 AstrBot 的 webchat 平台层，不在插件，也不在桥。**

要做，只有三条路：

| 方案 | 代价 | 风险 |
| --- | --- | --- |
| 改 AstrBot 核心，让 webchat 支持图片消息 | 大 | 升级会被覆盖，要维护补丁 |
| 写中间插件，把图片路径写到 App 能读的地方 | 中 | webchat 端仍显示不出来 |
| 给 meme_manager 提 issue 等作者支持 | 小 | 时间不可控 |

**顺带否定的一件事**：不要自己写"按情景挑表情包"的规则。
meme_manager 靠语义检索 + 情感模型 + 去重频控，那是几千行代码的工程，
一段提示词复刻不出效果。
